
Namzu 📚✨
Plataforma de Leitura Social e Gestão de Conhecimento.

O Namzu não é apenas mais um leitor de e-books ou uma rede social de livros. É um ecossistema projetado para quem deseja transformar a leitura em aprendizado estruturado, permitindo que usuários e grupos colaborem na construção de uma base de conhecimento sólida e organizada.

🚀 Sobre o Projeto
O nome Namzu remete à busca por sabedoria e fluidez de dados. O projeto foca em resolver a dispersão do conhecimento que ocorre em leituras individuais, oferecendo ferramentas para que grupos de estudo e entusiastas possam dissecar obras, criar correlações e gerenciar o que foi aprendido de forma sistêmica.

🛠️ Tecnologias Utilizadas
A arquitetura foi pensada para ser escalável e moderna:

Frontend: React / Next.js (Interface responsiva e SSR para SEO)

Backend: Node.js / Python (API robusta e processamento de dados)

Banco de Dados: PostgreSQL (Relacionamento de dados complexos)

Gestão de Estado: Context API ou Redux

💎 Funcionalidades Principais
Gestão de Conhecimento: Criação de notas, insights e conexões entre diferentes obras.

Grupos de Trabalho: Espaços focados em produtividade, onde o conhecimento é aplicado a projetos específicos.

Clube de Livros: Espaços de discussão social sobre obras, com foco em cronogramas e debates (Entidade separada dos Grupos de Trabalho).

Leitura Estruturada: Ferramentas para organizar o fluxo de leitura técnica e filosófica.

🏗️ Arquitetura de Dados
O sistema separa claramente os ambientes de interação para garantir que a colaboração técnica não se misture com a discussão social:

Workgroups (Grupos de Trabalho): Focados em entregas, documentação e aprendizado aplicado.

Book Clubs (Clubes de Livro): Focados na experiência compartilhada da leitura e troca de impressões.

Core Library: Onde o acervo e as anotações pessoais do usuário residem.
